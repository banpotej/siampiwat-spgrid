ตัวอย่าง: รายการงาน (Worklist)


      

        

          คำอธิบายตัวอย่าง
          

            

              แสดงข้อมูลเป็นรายการ ไม่ใช่ตารางหลายคอลัมน์: คอลัมน์เดียวใช้
              render สร้างรายการจากทั้งแถว (รหัส หมวด จำนวน สถานที่ วันที่
              และรายการชิ้น) หัวกลุ่มสองระดับ (สถานะ › เอกสาร) มาจาก
              groupBy โดยคอลัมน์กลุ่มซ่อนไว้และใช้ render
              สร้างข้อความหัวกลุ่ม ส่วนจำนวนของแต่ละระดับมาจาก
              labels.groupCount(count, { level, rows })
              ส่วนแถวหัวตารางถูกซ่อนด้วย CSS (ยังอ่านได้ด้วย screen reader)
              การค้นหาครอบคลุมเฉพาะคอลัมน์ที่แสดง
            

            

              ปุ่มที่ปลายแถบเครื่องมือสลับเป็นมุมมองปฏิทิน (viewToggle)
              โดยแต่ละรายการเป็นนัดที่เวลาวันที่ขอ (askedAt)
              คำค้นและตัวกรองคงอยู่เมื่อสลับ ส่วนการแบ่งหน้าและหัวกลุ่มแสดงเฉพาะมุมมองรายการ
              สลับจากโค้ดได้ด้วย setView('calendar')
            

            
new SPGrid(grid, {
  columns, rows, groupBy: ['status', 'doc'], hiddenColumns: ['status', 'doc'],
  labels: { groupCount: (n, { level }) => (level === 0 ? `${n} รายการ` : `· ${n} รายการ`) },
  calendar: { start: 'askedAt', title: 'code', subtitle: 'category' },
  defaultView: 'grid', viewToggle: true,
});
