ใช้ SPGrid กับ Claude Code

แนวทางให้ Claude Code (หรือ AI coding agent ตัวอื่น) เรียกใช้และศึกษา SPGrid ได้ถูกต้องในโปรเจกต์ของคุณ คู่มือสำหรับ agent AGENT_GUIDE.md แพ็กไปกับแพ็กเกจแล้ว ไม่ต้องคัดลอกไว้เอง

  1. ติดตั้งแพ็กเกจ ติดตั้งในโปรเจกต์ที่ใช้งานจริง agent จะอ่านคู่มือและ type ได้จาก node_modules ตรงเวอร์ชันที่ติดตั้ง 
    npm install @siampiwat/spgrid
  2. ชี้ให้ Claude Code อ่านคู่มือ เพิ่มบรรทัดนี้ใน CLAUDE.md หรือ AGENTS.md ของโปรเจกต์ (@path จะดึงไฟล์มาเป็นบริบทให้ทุก session) 
    ## SPGrid
ตารางข้อมูลใช้ @siampiwat/spgrid ห้ามเขียนตารางเอง
@node_modules/@siampiwat/spgrid/docs/AGENT_GUIDE.md
ตัวเลือกที่ไม่อยู่ในคู่มือย่อ ดู node_modules/@siampiwat/spgrid/docs/API.md
    ถ้าไม่ใช้ @path ก็ให้ agent อ่านไฟล์เดียวกันนี้เองก่อนเขียนโค้ด หรือ import เส้นทาง @siampiwat/spgrid/agent-guide ที่แพ็กเกจ export ไว้
  3. สั่งงานให้ชัดว่าต้องการอะไร บอกข้อมูล คอลัมน์ และพฤติกรรมที่ต้องการ แล้วให้ agent เลือกตัวเลือกของ SPGrid เอง 
    อ่าน AGENT_GUIDE.md ของ @siampiwat/spgrid ก่อน แล้วทำตารางรายการใบสั่งซื้อใน app/po/page.tsx
- คอลัมน์: เลขที่, ผู้ขาย, วันที่ (type date), มูลค่า (type number), สถานะ (badge)
- ค้นหาได้ แบ่งหน้า 20 แถว เรียงตามวันที่ล่าสุดก่อน
- ปุ่ม "ดู" ต่อแถว เปิดรายละเอียดด้วย showDetails
- ป้ายกำกับภาษาไทย (thaiLabels)
เมื่อเสร็จให้รัน dev server และเช็กว่า console ไม่มี error
  4. ลำดับที่ agent ควรศึกษา เริ่มจากไฟล์เล็กที่สรุปแล้วค่อยลงรายละเอียด อ่านเท่าที่งานต้องใช้ 
    1. docs/AGENT_GUIDE.md          สรุปการติดตั้ง คอลัมน์ อีเวนต์ ตัวเลือก และกฎที่ป้องกันบั๊ก
2. docs/API.md                 อ้างอิงเต็มทุกตัวเลือก เมธอด และธีม (--spg-*) เป็นภาษาไทย
3. dist/types/index.d.ts       type ที่แน่นอน เช่น Column, SPGridOptions (ใช้ผ่าน import type)
4. /purchase-order.html        ตัวอย่างเต็มรูปแบบ มีปุ่มดูโค้ดต้นฉบับ
5. /quick-start.html           ตัวอย่าง Next.js client component ที่ใช้ได้เลย
    ทุกพาธในข้อ 1–3 อยู่ใต้ node_modules/@siampiwat/spgrid/
  5. กฎที่ agent ต้องรู้ ข้อที่พลาดบ่อยที่สุด รายละเอียดครบอยู่ใน AGENT_GUIDE.md
    • ห้าม import ฝั่ง server SPGrid ต้องใช้ DOM ใน Next.js / React ให้สร้างใน useEffect ของ client component
    • หนึ่ง grid ต่อหนึ่ง container และเรียก destroy() ตอน unmount ข้อมูลใหม่ใช้ setRows() ห้ามสร้าง grid ซ้ำ
    • ฟังก์ชัน render ไม่ escape ให้ ต้องห่อข้อมูลผู้ใช้ด้วย escapeHtml()
    • ใส่ rowKey เมื่อแถวมี id และเก็บค่าดิบ (Date, number, boolean) ไว้ใน rows ให้ type จัดรูปแบบเอง
    • key ที่ไม่มีอยู่ หรือค่าที่ไม่ถูกต้องจะ throw RangeError / TypeError อย่าซ่อนด้วย try/catch
    • ปรับหน้าตาด้วยตัวแปร --spg-* อย่าแก้ไฟล์ CSS ของแพ็กเกจ
    • ยังไม่รองรับ server-side paging และ virtual scrolling (ข้อมูลทั้งหมดอยู่ในหน่วยความจำ) ส่วนการเลือกแถวมีแล้ว: selectable, selectionActions
    • เมื่อเปิด selectable ทุกแถวมีเซลล์ checkbox นำหน้า อย่าหาคอลัมน์ด้วยตำแหน่ง (td:nth-child) ให้ใช้ข้อมูลของแถวหรือ th[data-key] และใส่ rowKey เพื่อให้การเลือกอยู่ต่อหลัง setRows()
    • คำสั่งที่เปลี่ยนข้อมูล (อนุมัติ ยกเลิก ลบ) ใส่ confirm: true ใน selectionActions และตรวจเวอร์ชันที่ติดตั้งก่อนใช้ตัวเลือกใหม่ (ดู "Check the version first" ใน AGENT_GUIDE.md)
  6. ให้ agent ตรวจก่อนส่งงาน เพิ่มรายการนี้ในคำสั่งหรือ CLAUDE.md เพื่อให้ตรวจผลเองได้ 
    - new SPGrid ไม่ throw และ container.querySelector('table') มีแถวข้อมูล
- console ของเบราว์เซอร์ไม่มี error (RangeError จะบอกชื่อตัวเลือกที่ผิด)
- เรียก destroy() ตอน teardown และใช้ setRows() กับข้อมูลใหม่
- ทุก render function escape ค่าที่นำไปต่อเป็น HTML
- ถ้าใช้ selectable: ติ๊ก 2 แถวแล้ว getSelectedRows() ได้ 2 แถว และไม่มีโค้ดหรือเทสต์ที่หาเซลล์ด้วยตำแหน่ง
