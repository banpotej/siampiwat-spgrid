ตัวอย่าง: ธีมลาเวนเดอร์


      

        

          คำอธิบายตัวอย่าง
          

            

              ธีมสีม่วงอ่อน เปิดด้วยการใส่ class spg-theme-lavender (หรือ
              data-spg-theme="lavender") ที่ element ของตาราง หรือ element ใดๆ
              ที่ครอบอยู่ ธีมนี้ตั้งเฉพาะตัวแปร --spg-* จึงไม่กระทบตารางที่ไม่ใช้ธีม
            

            
grid.classList.add('spg-theme-lavender');
new SPGrid(grid, { columns, rows, striped: true, gridLines: 'both' });

// ปุ่ม action สีทึบ: คู่ class โทน + spg-action-solid
{ name: 'edit', label: 'แก้ไข', className: 'spg-action-warning spg-action-solid' }
