ตัวอย่าง: ปฏิทิน (Calendar)


      

        

          คำอธิบายตัวอย่าง
          

            

              ข้อมูลเดียวกับรายการของหาย: เอกสารที่รับเข้าแต่ละใบเป็นนัดหมายตามเวลารับ และทุกวันครบ
              30 วันจะมีนัด
              ย้าย Stock ตอน 09:00 (กดถัดไปสี่ครั้งเพื่อดูเดือนธันวาคม) ใส่ option
              calendar บอกว่าฟิลด์ไหนเป็นเวลาเริ่ม (start) เวลาสิ้นสุด
              (end) ชื่อเรื่อง และสถานที่ มีมุมมอง กำหนดการ / วัน / สัปดาห์ทำงาน /
              สัปดาห์ นัดที่เวลาซ้อนกันจะแบ่งความกว้าง ค้นหาและตัวกรองใช้ได้เหมือนตาราง
              คลิกนัดหรือกด Enter เพื่อเรียก onRowActivate (ที่นี่เปิดรายละเอียดด้วย
              showDetails)
            

            
new SPGrid(grid, {
  columns, rows,
  calendar: { start: 'start', end: 'end', title: 'subject', subtitle: 'place' },
  onRowActivate: ({ row }) => open(row),
});
