ตัวอย่าง: ธีมสีม่วง (Siam Piwat Purple)


      

        

          คำอธิบายตัวอย่าง
          

            

              ธีมสีม่วงประจำแบรนด์ (#3a2d4b) หัวตารางไล่เฉดม่วงอ่อน แถวสลับโทนม่วงนวล มีชุดสีโหมดมืด
              เปิดด้วยการใส่ class spg-theme-purple (หรือ
              data-spg-theme="purple") ที่ element ของตาราง หรือ element ใดๆ
              ที่ครอบอยู่ ธีมนี้ตั้งเฉพาะตัวแปร --spg-* จึงไม่กระทบตารางที่ไม่ใช้ธีม
            

            
grid.classList.add('spg-theme-purple');
new SPGrid(grid, { columns, rows, striped: true, gridLines: 'both' });

// ปุ่ม action สีทึบ: คู่ class โทน + spg-action-solid
{ name: 'edit', label: 'แก้ไข', className: 'spg-action-warning spg-action-solid' }
