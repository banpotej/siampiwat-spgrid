## สิ่งที่ทำ (ไฟล์เดียว: `src/styles/table.css`)

- กรอบตารางมีเงาบางๆ (`0 1px 3px`) ให้แยกจากพื้นหลังชัดขึ้น
- เส้นใต้หัวตารางเปลี่ยนจากเส้นเทาเข้ม 1px เป็น 2px โทนอ่อนลง (`color-mix` ของสี border กับ border-strong) ยังเด่นกว่าเส้นแถว
- เซลล์แรกและเซลล์สุดท้ายของแถวมี padding ด้านนอกเพิ่ม 4px (ใช้ `padding-inline` จึงรองรับ RTL) ตัวอักษรไม่ชิดขอบโค้ง
- หัวตารางแบบค้าง (`stickyHeader`) มีเงาเฉพาะด้านล่าง ตอนเลื่อนเห็นว่าหัวลอยอยู่
- อัปเดต `CHANGELOG.md` (หัวข้อ Changed)

## ข้อตัดสินใจ

- คำขอกว้าง ผมเลือกปรับแบบสุภาพและไม่เปลี่ยนโครงสร้าง ไม่แตะ markup, API, ตัวแปร `--dg-*` ที่มีอยู่ หรือสีหลัก
- ยังไม่เพิ่มตัวแปร CSS สาธารณะใหม่สำหรับเงา

## ข้อสังเกต

- เงาแรกที่ลองทำให้เกิดเส้นแนวตั้งจางๆ ระหว่างหัวคอลัมน์ในตารางแบบค้าง แก้โดยใช้ spread ติดลบ (`0 3px 3px -3px`) ให้เงาออกเฉพาะด้านล่าง
- `color-mix()` ต้องใช้เบราว์เซอร์ที่รองรับ (Chrome/Edge 111+, Safari 16.2+, Firefox 113+) ถ้าเบราว์เซอร์เก่ากว่านั้น เส้นใต้หัวตารางจะไม่แสดงสี
- ยังไม่ได้ดูหน้าจอแคบ โหมด compact และตารางที่มี action/ไอคอนครบทุกสถานะ
- ถ้าหมายถึงด้านอื่น (เช่น ขนาดตัวอักษร หัวตารางสีเข้ม แถวเลือก hover แบบมีแถบสี) บอกได้เลย
