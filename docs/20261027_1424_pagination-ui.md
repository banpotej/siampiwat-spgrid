## สิ่งที่ทำ

- ตัวเลือกใหม่: `pageSize`, `pageSizeOptions`, `onPageChange`, `labels.{pagination,summary,prev,next,pageSize}`
- เมธอดใหม่: `getPage`, `setPage`, `getPageSize`, `setPageSize` (ค่าไม่ถูกต้องโยน `RangeError`) และ `on('pageChange')`
- ลำดับ: กรอง → เรียง → แบ่งหน้า (`src/core/view.js` แบบ pure)
- pager เป็น `<nav aria-label>` นอกตาราง: Prev/Next, ปุ่มเลขหน้า (`aria-current="page"`), disable ที่หน้าแรก/สุดท้าย
- ข้อความสรุป "Showing X–Y of Z" (ว่างคือ "Showing 0 of 0") และ `<select>` เปลี่ยนจำนวนแถวต่อหน้า
- ค้นหา/กรอง/เรียง/เปลี่ยน page size → กลับหน้า 1; `setRows()` คงหน้าเดิมแต่ clamp
- listener click ตัวเดียวบน container ของ pager; หลังคลิก focus อยู่ที่ปุ่มเดิม (ถ้า disabled ย้ายไป `<nav>`)
- ไฟล์ใหม่: `render/pager.js`, `render/pagerEvents.js`, `render/labels.js`, `core/view.js`; `normalizeSort` ใน `core/sort.js`
- `examples/index.html` มี 25 แถว; อัปเดต `docs/API.md`, `CHANGELOG.md`, ROADMAP

## ข้อตัดสินใจที่เบี่ยงจากโจทย์

- เพิ่ม `examples/basic.html` (3 แถว) ให้ e2e ของ smoke/sort/filter ใช้ เพราะ index เป็น 25 แถว
- e2e ใช้ `pageSize: 5` แล้วเลือก 10 จาก select
- เขียนหน้าที่ถูก clamp กลับเข้า state เพื่อไม่ให้เด้งกลับ
