## ปัญหาเดิม

- ปุ่มทุกปุ่มเป็นสีน้ำเงินทึบ แถวที่มีหลายปุ่มดูฉูดฉาด แย่งความสนใจจากข้อมูล และปุ่ม Cancel ต้องเขียน CSS เองถึงจะต่างสี

## สิ่งที่ทำ

- สไตล์ tonal: พื้นหลังเป็นสีอ่อน (12% ของโทนผสมพื้น) ขอบ 40% ของโทน ตัวอักษรเป็นสีโทนเอง
  hover เข้มขึ้นเป็น 22% และขอบเต็มสี, กด 30% + ขยับลง 1px, focus ring เดิม, disabled จางลง
- โทนสีเดียว `--dgi-action-tone` (ค่าเริ่มต้น `--dg-accent`) ใช้สร้างพื้น/ขอบ/ตัวอักษรทั้งหมดผ่าน `color-mix()`
- class สำเร็จรูปใน `className`: `dg-action-danger`, `dg-action-success`, `dg-action-neutral`
  ค่าโทนเป็น `light-dark()` ให้สว่างขึ้นในโหมดมืดอัตโนมัติ (`#b91c1c`→`#f87171`, `#15803d`→`#4ade80`, `#374151`→`#d1d5db`)
- ตัวแปรใหม่: `--dg-action-tone`, `--dg-action-hover-bg`, `--dg-danger`, `--dg-success`, `--dg-neutral`
- ใช้ `dg-action-danger` ในปุ่ม Cancel ของ `examples/index.html` และ fixture e2e แทน CSS เฉพาะที่เขียนเอง (ลบ `.btn-cancel` ออก)
- อัปเดต `docs/API.md` และ `CHANGELOG.md`; ไฟล์ที่แก้ `src/styles/actions.css`, `src/styles/tokens.css`
- ความต่างสี (คำนวณคร่าวๆ): น้ำเงิน/แดงบนพื้นอ่อนราว 5.5–7:1 ผ่านเกณฑ์ WCAG AA ตัวอักษรปกติ (4.5:1) ยังไม่ได้วัดด้วยเครื่องมือ

## ข้อตัดสินใจ

- เลือก tonal แทนสีทึบ เพราะเป็นแนวทางที่คนใช้กันมากกับปุ่มในตาราง (ปุ่มรอง/ปุ่มในแถว) สีทึบเหมาะกับปุ่มหลักของหน้า
- ไม่เพิ่ม `variant` ใน `ActionDef` ใช้ `className` ที่มีอยู่ เพื่อไม่ขยาย public API

## ข้อสังเกต / ข้อควรระวัง

- **เปลี่ยนพฤติกรรม:** ผู้ที่ตั้งเฉพาะ `--dg-action-bg` เดิมได้พื้นทึบ+ตัวอักษรขาว ตอนนี้ตัวอักษรเป็นสีโทน (อ่านยากบนพื้นทึบ)
  ต้องตั้ง `--dg-action-color` คู่กัน ระบุไว้ใน CHANGELOG แล้ว (โปรเจกต์ยังเป็น `0.0.0` / Unreleased)
- `color-mix()` และ `light-dark()` ต้องใช้เบราว์เซอร์ใหม่ (`light-dark` ราว Chrome/Edge 123+, Safari 17.5+, Firefox 120+)
  ถ้าเก่ากว่านั้นสีโทน danger/success/neutral จะไม่ทำงาน
- ยังไม่ได้ดูโหมด compact, forced-colors และหน้าจอแคบ
- ถ้าต้องการให้ปุ่มหลัก (เช่น View) เป็นสีทึบ หรือให้เปลี่ยนเป็นปุ่มไอคอนอย่างเดียว บอกได้
