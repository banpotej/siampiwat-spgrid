# สรุปการดำเนินการ: ตารางมี border ทุกเซลล์ (`bordered`)

วันที่: 2026-10-28 | ประเภท: Implement feature | commit: ยังไม่ได้ commit

ดู screenshot `examples/basic.html` โหมดสว่างและมืดด้วยตาแล้ว CI บน GitHub ยังไม่ได้ตรวจ

## สิ่งที่ทำ

- ตัวเลือกใหม่ `bordered?: boolean` (ค่าเริ่มต้น `false`) เพิ่ม class `dg-bordered` ที่ `.dg-root`
- เพิ่มเส้นแนวตั้งระหว่างคอลัมน์ทั้งหัวตารางและตัวตาราง (เดิมมีเฉพาะกรอบนอกและเส้นแนวนอนของแถว)
  ใช้ `border-inline-end` กับทุกเซลล์ยกเว้นเซลล์สุดท้ายของแถว จึงไม่ซ้อนกับกรอบนอกและรองรับ RTL
- สีเส้นใช้ `--dg-border-color` เดิม (ปรับธีมสว่าง/มืดได้เอง); แถว "No data" ไม่มีเส้นแนวตั้ง
- โหมด forced-colors ใช้ `GrayText` เหมือนเส้นแถว
- เปิดใช้ใน `examples/index.html` และ `examples/basic.html`
- อัปเดต `docs/API.md` และ `CHANGELOG.md`; ขยาย test เดิม "look options" ใน `DataGrid.icons.test.js` ให้ตรวจ class `dg-bordered` (ปิดโดยค่าเริ่มต้น เปิดเมื่อตั้ง)

## ข้อตัดสินใจ

- คำขอ "ตารางขอให้มี border" ผมตีความเป็นเส้นขอบทุกเซลล์ (grid lines) เพราะกรอบนอกมีอยู่แล้ว
- ทำเป็น option แบบ opt-in เช่นเดียวกับ `striped` / `density` เพื่อไม่เปลี่ยนหน้าตาของผู้ใช้เดิม และเปิดในหน้าตัวอย่างให้เห็นผล
- ไม่เพิ่มตัวแปร CSS ใหม่ ใช้ตัวแปร border เดิม

## ข้อสังเกต

- test ตรวจเฉพาะ class ไม่ได้ตรวจหน้าตา เพราะ jsdom ไม่คำนวณ CSS การยืนยันหน้าตาใช้ screenshot ด้วยตาเท่านั้น
- ยังไม่ได้ดูร่วมกับ `stickyHeader`, แถวสลับสี (`striped`) และหน้าจอแคบ
- ถ้าต้องการเส้นเข้มขึ้น หรือคอลัมน์ action ไม่มีเส้น บอกได้
