ตัวอย่าง: ธีมสีทอง (Siam Piwat Solid Gold)


      

        

          คำอธิบายตัวอย่าง
          

            

              ธีมสีทองประจำแบรนด์ (#a28448) หัวตารางไล่เฉดทอง แถวสลับโทนครีม มีชุดสีโหมดมืด
              เปิดด้วยการใส่ class spg-theme-gold (หรือ
              data-spg-theme="gold") ที่ element ของตาราง หรือ element ใดๆ ที่ครอบอยู่
              ธีมนี้ตั้งเฉพาะตัวแปร --spg-* จึงไม่กระทบตารางที่ไม่ใช้ธีม
            

            
grid.classList.add('spg-theme-gold');
new SPGrid(grid, { columns, rows, striped: true, gridLines: 'both' });

// ปุ่ม action สีทึบ: คู่ class โทน + spg-action-solid
{ name: 'edit', label: 'แก้ไข', className: 'spg-action-warning spg-action-solid' }
