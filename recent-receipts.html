ตัวอย่าง: รับเข้าล่าสุด (Recent receipts)


      

        

          คำอธิบายตัวอย่าง
          

            

              การ์ดรายการสั้น ๆ: ชื่อการ์ดเป็น title จำนวนรายการที่มุมขวาเป็น
              rowCount: true (ข้อความมาจาก labels.rowCount)
              ไม่มีแถวหัวตารางเพราะตั้ง showHeader: false แต่ละแถวมีสองคอลัมน์: คอลัมน์
              render สร้างข้อความหลายบรรทัด (รหัส ชื่อ หมวด · จำนวน เวลา) และคอลัมน์
              type: 'badge' ที่ชิดขวา เวลาแบบ "วันนี้ 17:40" / "เมื่อวาน 16:41"
              คำนวณในฟังก์ชัน render เองจากฟิลด์ที่เป็น Date
            

            
new SPGrid(grid, {
