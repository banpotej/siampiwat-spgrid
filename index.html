SPGrid

ตารางข้อมูลสำหรับงานระบบองค์กร ค้นหา กรองหลายเงื่อนไข เรียงลำดับ จัดกลุ่ม แบ่งหน้า และส่งออก Excel ได้ในตัว ใช้กับ React, Next.js, Vue หรือ HTML ล้วน ไม่ต้องติดตั้งไลบรารีเพิ่ม ลองดูตัวอย่างที่ใช้งานได้จริงได้เลย

ดูตัวอย่างแรก การติดตั้ง Quick Start (Next.js) สำหรับ Claude Code

ความสามารถหลัก

  • ค้นหาและเรียงลำดับคลิกหัวคอลัมน์ ค้นหาทุกคอลัมน์หรือเลือกเฉพาะคอลัมน์ (ข้อความ ค่าจากรายการ ช่วงวันที่)
  • ตัวกรองขั้นสูงตั้งเงื่อนไขหลายข้อ เลือกให้ตรงทุกข้อหรือข้อใดข้อหนึ่ง เห็นจำนวนแถวที่เหลือทันที และสรุปเป็นชิปที่ลบทีละข้อได้
  • ส่งออก Excelเลือกฟิลด์ ค้นแถว และดูตัวอย่างก่อนส่งออก สร้างไฟล์ในเบราว์เซอร์
  • แบ่งหน้าเลือกจำนวนแถวต่อหน้า จำค่าที่เลือกไว้ได้
  • จัดคอลัมน์ซ่อน/แสดง ปรับความกว้าง ลากสลับตำแหน่ง และตรึงคอลัมน์
  • จัดกลุ่มแถวจัดกลุ่มตามคอลัมน์ พร้อมหัวกลุ่มที่ยุบได้
  • ชนิดคอลัมน์ข้อความ ตัวเลข วันที่ ใช่/ไม่ใช่ badge สถานะ และปุ่มต่อแถว
  • ปรับหน้าตาลายแถบ เส้นตาราง ความหนาแน่น โหมดมืด และธีมให้เลือกใช้
  • ใช้ได้ทุกที่ES modules ไม่มี dependency มี TypeScript types และคู่มือสำหรับ Claude Code

การติดตั้ง

  1. ข้อกำหนด Node.js 22 ขึ้นไป และ bundler ที่รองรับ ES modules (เช่น Vite, webpack) SPGrid ไม่มี runtime dependency
  2. ติดตั้งแพ็กเกจด้วย npm เผยแพร่บน npm แล้ว ติดตั้งได้ด้วย 
    npm install @siampiwat/spgrid
    หากติดตั้งผ่าน registry ไม่ได้ (เช่น ใช้ registry ภายใน) เลือกติดตั้งจาก URL หรือไฟล์ได้ 3 แบบ

    ก. จาก URL ของไฟล์ .tgz

    ไฟล์ .tgz แนบอยู่ที่ GitHub Releases (ถ้า repo เป็น private ต้องมี token) สร้างไฟล์เองด้วย npm run pack:release แล้วนำไปไว้บนที่ที่เปิดผ่าน URL ได้ 
    npm install https://github.com/banpotej/siampiwat-spgrid/releases/download/v2.0.15/siampiwat-spgrid-2.0.15.tgz

    ข. จาก git URL

    npm จะ build ให้ตอนติดตั้ง (สคริปต์ prepare) จึงต้องมี git บนเครื่องปลายทาง 
    npm install github:banpotej/siampiwat-spgrid
npm install github:banpotej/siampiwat-spgrid#main   # ระบุ branch หรือ tag

    ค. จากไฟล์ในเครื่อง

    ดาวน์โหลดแพ็กเกจที่แพ็กไว้แล้วติดตั้งจากไฟล์ได้เลย ดาวน์โหลด หรือ build และแพ็กไฟล์เองจาก repo นี้ 
    # ใน repo spgrid
npm install
npm run build
npm pack              # ได้ไฟล์ siampiwat-spgrid-2.0.15.tgz

# ในโปรเจกต์ที่จะใช้
npm install ../siampiwat-spgrid/siampiwat-spgrid-2.0.15.tgz
  3. ดาวน์โหลดเป็นไฟล์ .zip เนื้อหาเดียวกับแพ็กเกจ npm (dist/, docs/ รวมคู่มือสำหรับ AI Agent, README) แต่เป็น .zip สำหรับคนที่ไม่ใช้ npm แตกไฟล์แล้วใช้ dist/spgrid.js กับ dist/spgrid.css ดาวน์โหลด
  4. โหลดผ่าน URL ในหน้าเว็บ (ไม่ใช้ npm) ไฟล์ใน dist/ เป็น ES module ที่ไม่มี dependency ใช้ผ่าน URL ได้โดยตรง นำ dist/spgrid.js และ dist/spgrid.css ไปไว้บน static host หรือ CDN (เช่น jsDelivr / unpkg หลังเผยแพร่ขึ้น npm) หรือดาวน์โหลดไฟล์ที่ build แล้วจากที่นี่ ดาวน์โหลด spgrid.js ดาวน์โหลด spgrid.css ดาวน์โหลด spgrid.cjs 
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@siampiwat/spgrid@2.0.15/dist/spgrid.css" />
<div id="app"></div>
<script type="module">
  import { SPGrid } from 'https://cdn.jsdelivr.net/npm/@siampiwat/spgrid@2.0.15/dist/spgrid.js';

  new SPGrid(document.getElementById('app'), {
    rowKey: 'id',
    columns: [{ key: 'id', label: 'ID' }, { key: 'name', label: 'Name' }],
    rows: [{ id: 1, name: 'Ada' }],
  });
</script>
    URL ข้างบนใช้ jsDelivr (เมื่อเผยแพร่ขึ้น npm แล้ว) ควรระบุเวอร์ชันตายตัวแทน @latest หรือจะนำไฟล์ไปไว้บน static host ของตัวเองก็ได้
  5. นำเข้าและสร้างตาราง (เมื่อติดตั้งด้วย npm) import จาก spgrid จะดึง CSS มาให้ด้วย (ผ่าน bundler) ถ้าต้องการ JS อย่างเดียวใช้ @siampiwat/spgrid/plain หรือ import @siampiwat/spgrid/style.css เอง 
    import { SPGrid } from '@siampiwat/spgrid';

const grid = new SPGrid(document.querySelector('#app'), {
  rowKey: 'id',
  columns: [{ key: 'id', label: 'ID' }, { key: 'name', label: 'Name' }],
  rows: [{ id: 1, name: 'Ada' }],
});
  6. ใช้กับ framework SPGrid ทำงานกับ DOM จึงต้องสร้างฝั่งเบราว์เซอร์เท่านั้น เช่น ใน useEffect ของ React / Next.js (client component) แล้วเรียก grid.destroy() ตอน unmount
