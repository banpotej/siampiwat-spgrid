ตัวอย่าง: สรุปตามสถานะ (Status summary)


      

        

          คำอธิบายตัวอย่าง
          

            

              การ์ดสรุปเป็นแถบบาร์: ชื่อการ์ดเป็น title และบรรทัดรองเป็น
              description ไม่มีแถวหัวตาราง (showHeader: false)
              และไม่มีเส้นคั่น (gridLines: 'none') แต่ละแถวมีสามคอลัมน์: ชื่อสถานะ
              แถบบาร์ที่สร้างด้วย render (ความกว้างคือสัดส่วนของจำนวนต่อค่าสูงสุด
              สีมาจากข้อมูลและผ่าน escapeHtml) และจำนวนชิดขวา จำนวน 0 แสดงรางว่าง
            

            
new SPGrid(grid, {
  columns, rows, title: 'สรุป 2 ปี แยกตามสถานะ',
  description: 'นับเป็นรายการ — แยกตามสถานะปัจจุบัน (ย้อนหลัง 2 ปี)',
  showHeader: false, gridLines: 'none', labels: thaiLabels,
});
